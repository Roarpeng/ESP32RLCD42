## Cursor Cloud specific instructions

### Project Overview

This is an ESP-IDF v6.0.1 firmware project for the Waveshare ESP32-S3-RLCD-4.2 board (Xiaozhi AI voice assistant). The firmware binary cannot be run in the cloud VM — it must be flashed to physical ESP32-S3 hardware. The "application" for development purposes is the firmware build.

### Environment Setup

ESP-IDF v6.0.1 is installed at `/opt/esp/esp-idf`. Before running any `idf.py` commands, you must source the environment:

```bash
export IDF_PATH=/opt/esp/esp-idf
source /opt/esp/esp-idf/export.sh
```

### Building

```bash
cd /workspace
idf.py build
```

The output binary is at `build/ESP32RLCD42.bin`. A full clean rebuild takes ~8 minutes on 8 cores; incremental builds are much faster.

### Known Build Workarounds (ESP-IDF v6.0.1 Compatibility)

Several managed components (auto-downloaded by `idf_component_manager`) have compatibility issues with ESP-IDF v6.0.1:

1. **`espressif__bmi270_sensor`**: Missing prebuilt libraries for IDF 6.0. Workaround: create a symlink `ln -s 5.5 6.0` inside the component directory.
2. **`78__uart-uhci`**: Uses old GDMA API (`direction` field removed, `gdma_new_ahb_channel` signature changed in v6.0). Needs `esp_driver_dma` in `PRIV_REQUIRES` and the GDMA call updated to the new 3-parameter form.
3. **`espressif__esp_io_expander_tca9554`** and **`waveshare__custom_io_expander_ch32v003`**: Need `esp_driver_i2c` added to `REQUIRES` in their CMakeLists.txt.
4. **`sdkconfig`**: `CONFIG_LV_USE_IMGFONT` must be set to `y` for the `xiaozhi-fonts` emoji font component to compile.

If you delete `managed_components/` and re-download, you will need to re-apply these fixes. The update script handles this automatically.

### Lint / Test / Run

- **Lint**: No project-level linter is configured. Code style follows ESP-IDF conventions.
- **Tests**: No automated tests exist (the `test/` directory is a PlatformIO placeholder). Verification is done by successful `idf.py build`.
- **Run**: Cannot run in cloud VM — requires flashing to physical ESP32-S3 hardware via `idf.py -p PORT flash`.

### Project Structure

- `src/` — Main application source code
- `src/boards/waveshare-s3-rlcd-4.2/` — Board-specific code (display, sensors, UI)
- `components/` — Local project components
- `managed_components/` — Auto-downloaded ESP-IDF components (do not commit; regenerated by build)
- `mc_new/`, `mc_16m/` — Alternate component versions (reference/backup)
- `sdkconfig` — ESP-IDF build configuration
- `partitions/` — Flash partition table definitions
- `scripts/` — Utility scripts (asset generation, language config, etc.)
